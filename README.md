# Q4-Project
Reversi Game written in Java for Advanced CS class at Mountain View High School.
## Running
To run the project:
1. set `hostName` in ClientScreen to local IP or "localhost" if running on same machine
2. in one terminal, start Server by running `javac *.java && java Server`
3. in another terminal for each player, run `javac *.java && java Client`
## Controls
Click to place a stone
